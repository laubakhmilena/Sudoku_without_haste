# Судоку без спешки

Спокойная браузерная игра в судоку с несколькими вариантами правил, адаптивным интерфейсом, сохранением прогресса, статистикой и достижениями.

Проект работает прямо в браузере и написан на чистых HTML, CSS и JavaScript без фреймворков и сборщика.

## Возможности

- четыре режима судоку;
- автоматическая генерация головоломок с единственным решением;
- заметки-кандидаты;
- подсказки;
- мгновенная проверка ошибок;
- подсветка связанных клеток;
- пауза и продолжение партии;
- локальное сохранение текущей игры;
- облачная синхронизация через Yandex Games при доступном SDK;
- статистика завершённых партий;
- достижения;
- звуковые сигналы;
- русский и английский интерфейс;
- адаптивная вёрстка для компьютеров, планшетов и смартфонов;
- управление мышью, касанием и клавиатурой.

## Режимы игры

| Режим | Поле | Особенности |
|---|---:|---|
| **Диагонали** | 9×9 | Помимо строк, столбцов и блоков 3×3, числа не должны повторяться на двух главных диагоналях |
| **Острова** | 9×9 | Вместо стандартных блоков используются цветные области неправильной формы |
| **Классика** | 9×9 | Обычное судоку со строками, столбцами и блоками 3×3 |
| **Мини** | 6×6 | Короткая версия с числами 1–6 и блоками 2×3 |

## Как играть

1. Нажмите **Играть**.
2. Выберите режим.
3. Выберите пустую клетку.
4. Нажмите нужную цифру под игровым полем.
5. Заполните всю сетку без повторения чисел в соответствующих строках, столбцах и областях.

Кнопка **Заметки** позволяет добавлять в пустую клетку возможные варианты числа.

## Управление

### Мышь и сенсорный экран

- нажмите на клетку, чтобы выбрать её;
- нажмите на цифру, чтобы внести значение;
- используйте кнопки **Стереть**, **Заметки**, **Подсказка**, **Пауза** и **Новая**.

### Клавиатура

| Клавиша | Действие |
|---|---|
| `1`–`9` | Ввести число, доступное для текущего размера сетки |
| `0`, `Backspace`, `Delete` | Очистить выбранную клетку |
| `N` | Включить или выключить режим заметок |
| `↑` `↓` `←` `→` | Перемещаться между клетками |
| `Esc` | Закрыть открытое модальное окно |

## Настройки

В игре доступны:

- включение и отключение звуковых сигналов;
- автоматическая проверка неправильных значений;
- подсветка связанных клеток;
- полный сброс настроек, рекордов и текущей партии.

## Сохранение прогресса

Локальные данные сохраняются в браузере через `localStorage` под ключом:

```text
light_sudoku_save_v1
```

Сохраняются:

- текущая партия;
- выбранный режим;
- введённые числа и заметки;
- количество ошибок и подсказок;
- прошедшее время;
- настройки;
- лучшие результаты;
- статистика;
- достижения.

При доступном Yandex Games SDK игра также пытается синхронизировать данные с профилем игрока.

> Очистка данных сайта в браузере удалит локальное сохранение.

## Локальный запуск

Рекомендуется запускать игру через локальный HTTP-сервер.

### Вариант 1 — Python

Откройте терминал в папке проекта:

```bash
python -m http.server 8000
```

Если команда `python` не найдена:

```bash
py -m http.server 8000
```

Затем откройте:

```text
http://localhost:8000
```

### Вариант 2 — Visual Studio Code

1. Установите расширение **Live Server**.
2. Откройте папку проекта.
3. Нажмите правой кнопкой по `index.html`.
4. Выберите **Open with Live Server**.

Игра может открываться напрямую через `index.html`, но локальный сервер лучше воспроизводит условия веб-хостинга.

## Публикация через GitHub Pages

1. Откройте репозиторий на GitHub.
2. Перейдите в **Settings → Pages**.
3. В разделе **Build and deployment** выберите:
   - Source: `Deploy from a branch`;
   - Branch: `main`;
   - Folder: `/ (root)`.
4. Нажмите **Save**.
5. Дождитесь публикации.

После публикации игра будет доступна по адресу:

```text
https://laubakhmilena.github.io/SUDOKU/
```

## Yandex Games

В проекте предусмотрена интеграция с Yandex Games:

- `LoadingAPI.ready()`;
- `GameplayAPI.start()` и `GameplayAPI.stop()`;
- пауза и возобновление по событиям платформы;
- получение профиля игрока;
- облачное сохранение;
- rewarded-реклама для дополнительных подсказок;
- автоматическое определение языка платформы.

При локальном запуске без SDK основная игра продолжает работать, но рекламные и облачные функции недоступны.
